- **三种乐器演奏模式**：支持 **吉他 · 轮盘**（E2~E6 品格/24 和弦轮盘）、**吉他 · 36 键**（E3~D#6 延音直映射）与 **钢琴 · 36 键**（C4~B6 双修饰互斥批处理），支持 **2×2 智能织体编配**（原谱直出 / 1P 独奏 / 2P 柱式律动 / 2P 琶音根音）、**88 键音域热力条** 与 **一键智能移调**。
- **即插即用 MIDI 键盘直弹**：支持外接实体 MIDI 键盘（25/37/49/61/76/88 键自适应与热拔插自动重连）、61 键鼠标试弹预览、踏板延音及 24 和弦单键触发。
- **AI 智能扒谱**：音频转 MIDI（SheetSage2 / MERT），按需前置分离人声/器乐（HT-Demucs / Mel-Band RoFormer），支持 Intel Arc (XPU) / NVIDIA (CUDA) / AMD (ROCm) / CPU 跨硬件加速。
- **搜谱工坊与钢琴卷帘**：单窗内嵌「搜谱 / 多轨工坊」（联网搜谱、分轨清洗导出、双轨人声对齐）与增强型钢琴卷帘（视口裁剪、红框越界校验、实时泛音试听与直通重编）。
- **星曜双主题一体化工作站**：星曜暗夜 / 学院星昼双主题玻璃拟态，侧栏统一切换演奏台、MIDI 直弹、AI 扒谱、5 章图文《使用指南》、环境与显卡体检、并发极速检查更新（sha256 + 语法双校验与一键回退）。

## 快速上手（三步）

1. 双击 **`双击启动-异键演奏.bat`**，UAC 弹窗选“是”（演奏需管理员权限以向游戏发送键鼠输入）。
2. 在左侧栏选 **「乐器演奏台」**，从左侧曲库选曲、点 **「搜谱 / 多轨工坊」** 找谱，或切到 **「AI 智能扒谱」** 把音频转为 MIDI 后一键送入演奏台。
3. 选好乐器模式与编配角色（轮盘模式请先点 **「校准轮盘」** 对齐游戏内轮盘，36 键模式可点 **「智能移调」** 优化音域命中），切回游戏窗口按 **F8** 开始演奏，**F12** 随时紧急停止并全松键。
   - 外接 MIDI 键盘用户可直接点左侧 **「直弹 · 就绪 / MIDI 键盘直弹」** 即插即用直弹；新手随时可点左下角 **「使用指南」** 查阅 5 章图文教程。

## 两种使用方式

### A. 完整包（普通用户推荐）

- 把**整个文件夹**复制到任意路径，**不要只移动里面的单个文件**。文件夹名可以带中文、空格，也可以换盘符。
- 双击 `双击启动-异键演奏.bat` 即可。启动器优先使用包内 `runtime\python311`，该运行时纯相对路径解析依赖，复制/改名/带空格/换电脑都能直接启动。
- 首次运行建议点左侧栏 **「环境与显卡体检」**，确认显卡加速、模型、音频与输入通道均就绪。
- 系统要求：Windows 10/11 64 位；向游戏内自动演奏或实时直弹需要管理员权限。

### B. GitHub 源码（开发者）

- 安装 64 位 **Python 3.11**（python.org），安装时勾选 “Add python.exe to PATH”。
- 双击 `setup\一键配置环境与模型.bat`：自动创建 `.venv` / `vendor\sheetsage2\.venv` 并下载依赖。模型权重约 2.6GB，且是 **gated** 仓库——按脚本提示在 HuggingFace 模型页接受条款并登录一次即可。
- 双击 `双击环境自检.bat`，再双击启动器。
- 模型权重为 **CC BY-NC 4.0（仅限非商业）**，第三方许可见 `licenses\`。

## 常见排障

- **按键没反应**：确认以管理员权限启动（查看左下角 `管理: 有`）、游戏窗口在前台（建议设“无边框窗口化”）；也可展开控制舱右侧「硬件自检（4 步）」/「键盘通道自检」排查。
- **轮盘位置不对**：吉他轮盘模式下点「校准轮盘」，拖圆心、滚轮或 `[-][+]` 调半径，回车确认。
- **扒谱没声音/很慢**：点左侧「环境与显卡体检」或双击 `双击环境自检.bat`，确认推理设备为 XPU / CUDA / ROCm / CPU；未安装加速环境时默认回退 CPU 推理（约 2~4 分钟/首，属正常速度）。
- **检查更新卡住或需要回滚**：点击左侧「检查更新」并发探测最快镜像；更新前会自动备份至 `logs\backup_prev\`，随时可在更新页一键回退上一版本。
- **换电脑后打不开**：先双击 `双击环境自检.bat`，启动器会自动修复虚拟环境路径；如仍异常请重跑 `setup\一键配置环境与模型.bat`。
- **界面字体发虚**：系统需安装「微软雅黑 UI」（Windows 10/11 自带）。

## 目录说明

```text
main.py                 统一入口
gui_main.py             一体化工作站主壳（侧栏导航 + 6 页内嵌 + 轮盘校准）
gui_theme.py            星曜暗夜 / 学院星昼双主题玻璃拟态样式
ui_widgets.py           矢量图标、舞台背景、艺术头图、音域热力条等自绘组件
guide_dialog.py         内置 5 章图文《使用指南》
updater.py              并发多镜像探测、sha256/语法校验、原子更新与回退
core_utils.py           公共路径、日志轮转与便携虚拟环境自愈
transcriber/            AI 扒谱流水线（SheetSage2 / MERT + 按需音源分离）
player/                 三模式编配与编译、发送引擎、钢琴卷帘、搜谱工坊、MIDI 直弹
assets/                 内置测试 MIDI 与舞台美术资产
vendor/sheetsage2/      推理环境、模型权重、CLI
runtime/python311/      便携 Python 3.11 运行时（完整包自带）
setup/                  环境配置、模型下载、虚拟环境自愈
logs/                   运行日志、自检报告与更新备份
out/                    扒谱、搜谱与导入 MIDI 默认输出目录
```
